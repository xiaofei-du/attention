# 長回覆測試範例

以下保留原型開發期間的示範內容，用來驗證長回覆會另取口語摘要。這是一份歷史測試範例，不是目前安裝狀態。

通知處理已分成三部分：原任務產生口語摘要，停止事件將摘要存入本機隊列，獨立播放程序再按順序朗讀。多個任務同時完成時，只有取得播放鎖的程序可以出聲；其他摘要留在隊列等待。

目前的驗證包含摘要格式、重複事件、先後順序，以及暫停後繼續播放。沒有合格摘要的長回覆會略過，不會另外開啟模型來重新總結。完整技術回答保留在畫面，通知只朗讀後面的摘要內容。下面的示範摘要記錄的是原型尚未接入真實任務時的情況。
