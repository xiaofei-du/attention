# Attention agent guide

Read [CONTRIBUTING.md](CONTRIBUTING.md) before preparing commits or pull requests.
Use semantic commit subjects and PR titles, and the **Because** / **This commit**
body format. Include actual verification results and material limitations.

For runtime changes, follow the build and test instructions in
[README.md](README.md#build-from-source), and regenerate the published packages
when their sources change. Documentation-only changes need formatting and link
checks, not an unrelated full runtime test run.
